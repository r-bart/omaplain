# Atribuciones

## Código

OmaPlain es una implementación clean-room y no contiene código de Pure Paste. El código de este repositorio se distribuye bajo GPL-3.0-or-later.

El plugin invoca, pero no incorpora ni enlaza, herramientas existentes del sistema: Omarchy Shell, Quickshell, Hyprland, wl-clipboard, Python y util-linux.

## Datos de reglas

`data/tracking-parameters.json` y `data/structural-mime-types.json` fueron creados para OmaPlain a partir de identificadores públicos e interoperables observados en aplicaciones. Se ofrecen bajo CC0-1.0. No se descargan ni actualizan en runtime.

Los nombres de productos y proyectos pertenecen a sus respectivos titulares.
