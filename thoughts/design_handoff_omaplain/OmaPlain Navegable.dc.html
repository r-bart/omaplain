{{ historyCaret }} Why can the original still show up?
Cleaning replaces what is on the clipboard, but Omarchy's own history keeps every entry it saw. If a rule changed characters, the history may hold both versions until you clear it.
Cleaning
Remove rich formatting
Pastes using only the plain-text representation.
Remove link tracking
Only when the clipboard is one whole link. Signed links are left alone.
Remove invisible characters
Keeps emoji, right-to-left writing and language marks.
{{ optionalCaret }} Optional
Normalise quotes
Turns typographic quotes into straight ones.
